# Mapa de estudo

Tudo o que estudar para ir da base da computação ao nível sênior em desenvolvimento de software, com finanças e segurança, **em ordem de pré-requisito**: cada assunto só aparece depois de tudo o que ele usa.

Cada assunto tem um arquivo próprio que explica o que é, por que existe, como funciona por baixo, qualidades e defeitos, erros comuns, o que o mercado cobra, exercícios em 4 níveis e as fontes conferidas.

## Como usar

1. Abra o **[MAPA](MAPA.md)** e siga as etapas de cima para baixo (Etapa 0 é a base de tudo).
2. Quando chegar num assunto, abra o arquivo dele (📘 no mapa).
3. Estude pelo método do assunto 0.1, **[Aprender a aprender](assuntos/00-aprender-a-aprender/aprender-a-aprender.md)**: testar-se em vez de reler, espaçar as revisões, misturar tipos de problema e ensinar.
4. Só avance quando cumprir o critério "como saber que dominou" do arquivo.

### Níveis

| Nível | Nome | Quer dizer |
|---|---|---|
| N1 | Conhecer | Sabe o que é, para que serve e quando usar. |
| N2 | Usar | Faz funcionar com documentação aberta. |
| N3 | A fundo | Faz sem consulta e explica como funciona por dentro. |
| N4 | Dominar | Ensina, decide trade-offs e revisa o trabalho dos outros e da IA. |

## Como cada arquivo é escrito

Nenhum arquivo é publicado como 📘 sem passar pelo [protocolo de escrita](MAPA.md#como-cada-arquivo-é-escrito): fonte primária na versão atual, pesquisa do momento, todo código executado, fatos conferidos e cabeçalho com `verificado-em`, versões e fontes. O que não deu para confirmar sai do arquivo ou fica marcado como pendente.
